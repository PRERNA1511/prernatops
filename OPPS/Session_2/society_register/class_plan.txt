SECTION 2: METHOD EXPLANATIONS
================================================================

Flat::setDetails(name, flatNo, id)
  - Sets all three data members at once.
  - Sets occupied = true to mark the slot as filled.

Flat::displayRow(int serial)
  - Prints one row in the members table.
  - Uses iomanip::setw() for aligned columns.

Flat::displayDetail()
  - Prints a boxed, detailed view of one flat's info.

SocietyRegister::addMember()
  - Reads input from user.
  - Validates: checks if flatNumber is already taken.
  - Creates Flat object by calling setDetails().

SocietyRegister::sortByFlatNo()
  - Implements bubble sort on the members[] array.
  - Swaps Flat objects directly (copy by value).
  - After sorting, calls displayAll() to show result.

SocietyRegister::displayHeader()
  - Private helper that prints the column headers.
  - Called internally by displayAll() and sortByFlatNo().

SocietyRegister::toLower()
  - Private helper for case-insensitive search.
  - Converts each character using tolower().

SECTION 3: KEY C++ CONCEPTS DEMONSTRATED (Session 2)
================================================================

1. CLASS DEFINITION
   - Keyword: class
   - Sections: private: and public:
   - Members: data (attributes) and functions (methods)

2. OBJECTS
   - SocietyRegister reg;    --> creates one object named 'reg'
   - Flat members[50];       --> array of 50 Flat objects

3. ACCESS SPECIFIERS
   - private:  data members (ownerName, flatNumber, ownerId)
   - public:   all methods (getters, setters, display, etc.)

4. CONSTRUCTOR
   - Flat()         -- default constructor (empty flat)
   - Flat(...)      -- parameterized constructor (pre-filled flat)
   - SocietyRegister() -- initializes total=0

5. MEMBER FUNCTIONS
   - Called using: objectName.functionName()
   - Example: reg.addMember(), members[i].displayRow(i+1)

6. this POINTER (implicit)
   - When methods access ownerName, they use this->ownerName

7. CONST METHODS
   - Declared with 'const' at the end: getFlatNo() const
   - Cannot modify the object's data

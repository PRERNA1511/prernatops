================================================================
NOTE: DESTRUCTION ORDER
================================================================
Objects are destroyed in REVERSE ORDER of creation (LIFO):
  Created:  f1 → f2 → f3 → f4 → f5
  Destroyed: f5 → f4 → f3 → f2 → f1

This is because local variables are stored on the STACK, and
the stack follows Last-In-First-Out (LIFO) ordering.

KEY CONCEPTS SUMMARY
================================================================

CONSTRUCTOR TYPES:
  1. Default Constructor     → Flat()
     Called when: Flat f1;
     Purpose: Initialize with default/empty values

  2. Parameterized Constructor → Flat(name, flatNo, id)
     Called when: Flat f2("Aarav", 101, 1001);
     Purpose: Initialize with specific values directly

  3. Copy Constructor        → Flat(const Flat &other)
     Called when: Flat f3 = f2; OR Flat f4(f2);
     Purpose: Create an INDEPENDENT COPY of an existing object

  4. Destructor              → ~Flat()
     Called when: Object goes out of scope, OR delete is called
     Purpose: Clean up resources (close files, free memory, etc.)

RULES:
  ✓ If no constructor is defined, C++ provides a default one
  ✓ If any constructor is defined, default constructor is NOT auto-provided
  ✓ Destructor cannot be overloaded (only one per class)
  ✓ Destructor takes no parameters and returns nothing
  ✓ Copy constructor takes a const reference to the same class
  ✓ Initialization list (:member(value)) is more efficient than assignment

STATIC objectCount USAGE:
  - Declared inside Flat class: static int objectCount;
  - Defined outside: int Flat::objectCount = 0;
  - Incremented in ALL constructors
  - Decremented in destructor
  - Shows exact number of living Flat objects at any time

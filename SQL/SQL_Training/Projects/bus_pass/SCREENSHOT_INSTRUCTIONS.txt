The following screenshot files need to be captured manually
in MySQL Workbench and saved in this folder:

------------------------------------------------------------
FILE 1: workbench_connected.png
------------------------------------------------------------
PURPOSE : Shows MySQL Workbench successfully connected to MySQL Server.

HOW TO CAPTURE:
  1. Open MySQL Workbench.
  2. On the Home screen, you should see your connection tile.
  3. Double-click the connection to open it.
  4. You will see the SQL Editor with the Schemas panel on the left.
  5. Press Windows + Shift + S (Snipping Tool) to take a screenshot.
  6. Save the file as: workbench_connected.png
  7. Place it in this folder: Projects/bus_pass/

WHAT SHOULD BE VISIBLE IN THE SCREENSHOT:
  - MySQL Workbench window fully open
  - A connection tab at the top (e.g., "Local instance MySQL80")
  - The Navigator panel on the left showing Schemas
  - The SQL Editor in the center
  - Connection info in the status bar at the bottom

------------------------------------------------------------
FILE 2: passengers_table.png
------------------------------------------------------------
PURPOSE : Shows the structure of the passengers table.

HOW TO CAPTURE:
  1. In MySQL Workbench, open a new SQL tab.
  2. Type and run the following query:
       USE bus_pass;
       DESCRIBE passengers;
  3. The Result Grid at the bottom will show columns, types, nulls, keys.
  4. Take a screenshot of the Result Grid.
  5. Save as: passengers_table.png
  6. Place it in this folder: Projects/bus_pass/

WHAT SHOULD BE VISIBLE:
  - The DESCRIBE passengers output showing all 8 columns:
    passenger_id, full_name, roll_number, class, section,
    contact_number, address, created_at
  - Column types, Null, Key, Default, Extra information
  - "8 row(s) returned" in the Action Output panel

------------------------------------------------------------
NOTE: These screenshots CANNOT be auto-generated by a program.
      They must be captured manually while MySQL Workbench is running
      with an active database connection.
